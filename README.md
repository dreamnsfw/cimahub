# سيما هَب — CimaHub

موقع عربي متجاوب للأفلام والمسلسلات والأنمي، بخادم Node.js وبيانات TMDB. لا يحتاج حزمًا خارجية أو خطوة بناء.

## التشغيل

يتطلب Node.js 22 أو أحدث. عند إعداد جهاز جديد انسخ `.env.example` إلى `.env` وأدخل مفتاح TMDB. لا تنشر `.env`.

```powershell
npm start
# أثناء التطوير
npm run dev
# الاختبارات في Windows المقيد
node --test --experimental-test-isolation=none
```

افتح `http://127.0.0.1:3000`.

## الصفحات والفهرسة

الرئيسية والأفلام والمسلسلات والأنمي والأعلى تقييمًا والجديد والحلقات والمواسم والبحث ترجع HTML من الخادم. تفاصيل العمل لها رابط ثابت من الاسم والسنة مثل `/family-guy-1999/`، والموسم `/family-guy-1999/season/1/` والحلقة `/family-guy-1999/season/1/episode/1/`.

روابط الأفلام الرقمية القديمة تتحول 301. روابط `/#/details/...` تتحول في المتصفح لأن الجزء بعد # لا يصل إلى الخادم. العنوان والوصف وcanonical وOpen Graph وTwitter والبيانات المنظمة مستقلة لكل صفحة. صفحات الفلاتر والبحث والنتائج الفارغة noindex؛ الترقيم له canonical ذاتي، والأخطاء ترجع 404 أو 5xx حقيقيًا.

توجد خرائط `/sitemap.xml` و`/sitemap-categories.xml` وأجزاء `/sitemap-movies-N.xml` وخريطة الفيديو `/sitemap-videos.xml` عند وجود بيانات مؤهلة. الاسم movies في أجزاء الخريطة تاريخي؛ المحتوى يشمل الأفلام والمسلسلات والمواسم والحلقات المؤهلة المعروفة والصور. توجد 31 صفحة لأنواع أفلام ومسلسلات الأنمي بروابط مثل `/anime/movies/genre/action/`، وتضاف للخريطة بعد ظهور نتائج قابلة للفهرسة.

## الصور والجودة

الصور تحمل أسماء وصفية مثل `spider-man-brand-new-day-2026-poster.jpg`. يربطها الخادم بمصدر TMDB الثابت ويحفظها محليًا عند أول طلب. لا يقبل وكيل الصور عنوانًا خارجيًا اعتباطيًا. تتغير لاحقة الصورة عندما يتغير أصلها، وتظل أسماء الصفحات ثابتة عند تغير العنوان في المصدر.

تستخدم الأعمال المصنفة Animation كلمة «أنمي» وفق سياسة الموقع، بما فيها الأعمال الغربية. الأعمال العربية لا تحمل «مترجم». تضاف HD أو HD 720p/1080p/2160p إلى عنوان ووصف العمل عند تسجيل جودة مناسبة مع مصدر صالح؛ لا تعتبر HDCAM أو HDTS جودة HD. هذه إشارة بيانات المصدر وليست فحصًا تقنيًا للفيديو. لا تظهر عبارة بديلة للجودة الناقصة. تقييمات TMDB ظاهرة باسم المصدر ولا تُنسخ إلى AggregateRating.

المشغل المتوفر موجود في HTML نفسه. تُجلب بيانات VideoObject المطابقة من صفحة المصدر وتُحفظ في `data/source-video-metadata/` مع صورة فيديو محلية باسم العمل. يدعم `data/video-metadata.json` التجاوز اليدوي، ولا تُختلق تواريخ نشر أو مدد. راجع الدليل أدناه.

أثناء تشغيل الخادم يفحص `qfilm-discovery.js` إضافات الرئيسية وأول صفحات الأقسام الإقليمية والسنة الحالية كل 30 دقيقة. تُحفظ المطابقات الجديدة في `data/qfilm-new-import.json`؛ الأسماء أو السنوات الملتبسة تنتظر المراجعة. لا تعتمد المتابعة على زيارة المستخدم للعمل أو شعبية TMDB. ترتيب `/recent/` يبقى حسب الصدور/العرض.

## البيانات والنشر

احفظ `data/` و`public/uploads/` على قرص دائم وخذ نسخًا احتياطية، خصوصًا `data/seo-catalog.json` الذي يثبت أسماء الصفحات والصور. لا تحذفه عند النقل. التصميم الحالي لعملية خادم واحدة؛ تعدد النسخ يحتاج مخزنًا مشتركًا وتسلسل كتابة مشتركًا.

اضبط `SITE_URL=https://cimahub.net` عند النشر الفعلي على هذا النطاق، مع HTTPS وHOST/PORT المناسبين. محليًا تبقى الروابط الأساسية على عنوان الاختبار. لم يُنشر الموقع ولم يُربط بـ Search Console تلقائيًا.

الخادم يحفظ المفتاح خارج المتصفح ويتحقق من المدخلات ويطبق مهلة اتصال وإعادة محاولة وتخزين بيانات خمس دقائق وصفحات HTML دقيقة واحدة. توجد حدود طلبات API وترويسات أمان. الفلاتر الإقليمية تعتمد على لغة العمل الأصلية.

للقصص العربية الأولوية؛ عند غيابها تُستخدم ترجمة آلية محفوظة عبر MyMemory، وقد تحتاج مراجعة تحريرية. لا تُحفظ رسائل فشل الخدمة كقصص. قد تتعطل مصادر المشاهدة الخارجية بصورة مستقلة عن الموقع.
